# Git Remote Branch Practice

This repository demonstrates the Git workflows from an introductory remote-branch lab.

## Topics practiced

- Create and merge a local feature branch (`testing`).
- Push `main` and `testing` to a remote repository.
- Clone the repository into another working directory.
- Fetch and merge when local and remote branches diverge.
- Resolve a text-file merge conflict by retaining both intended changes.
- Push subsequent commits and synchronize remote updates.

## Contents

- `edition.txt`: a small text file revised across commits, including conflict resolution.
- `new_feature.txt`: a change originally developed on the `testing` branch.

Use `git log --oneline --graph --all --decorate` to inspect the branching and merge history.
